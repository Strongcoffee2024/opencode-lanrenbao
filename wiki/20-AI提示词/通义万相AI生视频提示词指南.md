# 通义万相 AI 视频生成提示词指南

## 核心概念
> 通义万相（Wanx 2.2）是阿里推出的 AI 视频生成模型，本指南系统整理了 14 大类提示词维度，涵盖光线、时间段、景别、构图、镜头焦段、机位角度、镜头类型、色调、运动、人物情绪、基础运镜、高级运镜、视觉风格和特效镜头，是 AI 视频创作的完整提示词参考手册。

## 详细解析

### 一、光线（12 种）

| 类型 | 核心要点 | 适用场景 |
|------|----------|----------|
| **晴天光** | 日光、侧光、中景、低饱和度 | 日常室内/室外自然光场景 |
| **柔光** | 日落、边缘光、暖色调、低饱和度 | 温馨浪漫氛围 |
| **硬光** | 侧光、高对比度、中焦距 | 安静沉思、戏剧性场景 |
| **顶光** | 干净单人镜头、长焦特写 | 面部特写、紧张感 |
| **侧光** | 黄昏、边缘光、中心构图 | 人物情绪表达 |
| **背光** | 中焦距、低对比度、日光 | 慵懒放松场景 |
| **底光** | 黎明、火光、暖色调 | 神秘/紧张氛围 |
| **边缘光** | 黄昏、双人镜头、暖色调 | 人物轮廓突出 |
| **剪影** | 混合色调、全景、高对比度 | 孤独旅程、史诗感 |
| **低对比度** | 复古风格、昏暗色彩 | 70年代怀旧感 |
| **高对比度** | 高饱和度、暖色调 | 戏剧性情感表达 |

### 二、时间段（6 种）

| 类型 | 光线特征 | 色调倾向 |
|------|----------|----------|
| **白天** | 柔光、侧光、边缘光 | 暖色调 |
| **夜晚** | 实用光、混合光、顶光 | 高饱和度 |
| **黄昏** | 柔光、侧光、冷色调 | 低饱和度 |
| **日落** | 侧光、边缘光、柔光 | 冷/暖色调均可 |
| **黎明** | 火光、冷色调、低对比度 | 冷色调 |
| **日出** | 侧光、边缘光、暖色调 | 低饱和度 |

### 三、景别（7 种）

从近到远：**特写 → 近景 → 中景 → 中近景 → 中全景 → 全景 → 广角**

- **特写**：面部细节，突出情绪
- **近景**：胸部以上，人物交流
- **中景**：腰部以上，人物动作
- **中近景**：介于近景与中景之间
- **中全景**：全身+部分环境
- **全景**：完整场景展现
- **广角**：宏大场景，定场镜头

### 四、构图（5 种）

| 类型 | 特点 | 效果 |
|------|------|------|
| **中心构图** | 主体居中 | 突出焦点 |
| **平衡构图** | 左右均衡 | 稳定和谐 |
| **左/右侧重构图** | 主体偏一侧 | 动态张力 |
| **对称构图** | 镜像对称 | 庄重仪式感 |
| **短边构图** | 利用短边空间 | 紧凑压迫感 |

### 五、镜头焦段（5 种）

**中焦距 → 广角 → 长焦 → 望远 → 超广角-鱼眼**

- **中焦距**：自然视角，日常对话
- **广角**：环境交代，空间感强
- **长焦**：压缩空间，突出主体
- **望远**：远距离拍摄，野生动物
- **超广角-鱼眼**：夸张变形，群像镜头

### 六、机位角度（6 种）

| 类型 | 视角 | 情绪效果 |
|------|------|----------|
| **过肩角度** | 越过肩膀拍摄 | 对话交流感 |
| **高角度** | 从上往下 | 渺小、弱势 |
| **低角度** | 从下往上 | 权威、力量 |
| **倾斜角度** | 歪斜机位 | 不安、混乱 |
| **航拍** | 空中俯视 | 宏大壮观 |
| **俯视角度** | 垂直向下 | 亲密、脆弱 |

### 七、镜头类型（5 种）

- **干净单人镜头**：单一主体，背景虚化
- **双人镜头**：两人互动，过肩/平衡
- **三人镜头**：三人场景，群像感
- **群像镜头**：多人场面，氛围营造
- **定场镜头**：场景交代，建立空间

### 八、色调（4 种）

| 类型 | 情绪 | 典型场景 |
|------|------|----------|
| **暖色调** | 温馨、喜悦 | 日落、室内 |
| **冷色调** | 宁静、孤独 | 夜晚、雨天 |
| **高饱和度** | 活力、强烈 | 运动、节日 |
| **低饱和度** | 沉稳、忧郁 | 老人、沉思 |

### 九、运动（10 种）

街舞、跑步、滑滑板、踢足球、网球、乒乓球、滑雪、篮球、橄榄球、顶碗舞、侧手翻

> **提示词技巧**：运动类提示词需包含动作细节、镜头跟随方式、环境互动三个要素。

### 十、人物情绪（5 种）

| 情绪 | 面部特征 | 身体语言 |
|------|----------|----------|
| **愤怒** | 皱眉、咬牙 | 紧绷、前倾 |
| **恐惧** | 瞳孔放大、嘴唇微张 | 僵硬、后退 |
| **高兴** | 眼睛闪烁、微笑 | 放松、开放 |
| **悲伤** | 眼神空洞、流泪 | 低头、蜷缩 |
| **惊讶** | 睁大眼睛、张嘴 | 后退、停顿 |

### 十一、基础运镜（4 种）

- **镜头推进**：拉近主体，突出细节
- **镜头拉远**：展现环境，交代关系
- **镜头向右/左移动**：跟随运动，揭示新信息
- **镜头上摇**：从下往上，展现高度/渺小感

### 十二、高级运镜（4 种）

| 类型 | 技术要点 | 适用场景 |
|------|----------|----------|
| **手持镜头** | 动态模糊、真实感 | 纪实、紧张场景 |
| **复合运镜** | 多镜头组合 | 复杂场景转换 |
| **跟随镜头** | 镜头跟随主体 | 运动、行走 |
| **环绕运镜** | 360°环绕主体 | 戏剧性、英雄时刻 |

### 十三、视觉风格（10 种）

毛毡风格、3D 卡通、像素风格、木偶动画、3D 游戏、黏土风格、二次元、水彩画、黑白动画、油画风格

> **提示词技巧**：风格类提示词需在开头明确声明风格类型，如"3D 卡通风格，..."或"油画风格，..."。

### 十四、特效镜头（2 种）

- **移轴摄影**：微缩世界效果，高角度俯瞰
- **延时拍摄**：时间压缩，展现变化过程

### 提示词结构公式

```
[光线] + [时间段] + [景别] + [构图] + [镜头焦段] + [机位角度] + [色调] + [主体描述] + [动作/情绪] + [环境/背景] + [运镜方式]
```

**示例**：
> 柔光，黄昏，侧光，低饱和度，冷色调，中心构图，中近景，一个娇小的女孩站在夜晚的街道旁，周围是渐暗的暮色。她有着棕色卷发，披肩自然垂落，脸颊泛红，泪水沿着脸庞缓缓滑落。背景是一条空旷的城市道路，远处街灯刚刚亮起。
